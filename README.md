# RAJEEV-iOS-Development

This repository contains multiple iOS sample projects and demos. Each project is kept in its own folder and has its own README that explains the purpose, architecture, and setup for that specific app.

## Folder naming convention

Each project folder follows a numbered naming pattern such as `P1-...`, `P2-...`, `P3-...`, and so on.

- `P1` stands for Project 1
- `P2` stands for Project 2
- `P3` stands for Project 3
- This pattern continues as more demo projects are added

This naming convention keeps the repository organized by project order and makes it easy to identify the sequence of iOS learning projects.

- The root `README.md` gives a high-level overview of the repository.
- Each project folder contains its own `README.md` for project-specific details.
- Inside every project folder, you will usually find the Xcode project file and the actual Swift source code for that app.

This keeps the repository organized by topic and makes it easier to explore each iOS implementation separately.
